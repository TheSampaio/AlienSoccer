<h1>Alien Soccer</h1>
    <section>
        <p>
            <strong>Alien Soccer</strong> is a mini-game made in Java, designed to practice my skills in game engine architecture, 
            object-oriented programming (OOP), and Java itself. The game engine was built entirely using Java's standard interfaces 
            and abstractions, including <code>JFrame</code>, <code>Canvas</code>, <code>Graphics</code>, <code>Rectangle</code>, and more.
        </p>
    </section>
    <img src="data/image/showcase.jpg" width="850" alt="Alien Soccer Showcase">
    <h2>Features</h2>
    <ul>
        <li>Built from scratch using Java's native libraries</li>
        <li>Object-oriented game engine design</li>
    </ul>
